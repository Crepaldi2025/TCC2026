# Resultados

Esta pasta é destinada aos arquivos de saída gerados pelos notebooks do projeto.

Podem ser incluídos, por exemplo:

- métricas de desempenho dos modelos;
- previsões diárias;
- previsões em resolução de 5 minutos;
- tabelas de comparação estatística;
- gráficos finais;
- arquivos de resumo associados a uma versão específica do TCC.

Os resultados utilizados na versão final do TCC devem ser preservados por meio de uma versão ou release específica do repositório.

Novos resultados obtidos com dados adicionais do protótipo deverão ser adicionados em versões posteriores, sem substituir silenciosamente os resultados originalmente apresentados.
