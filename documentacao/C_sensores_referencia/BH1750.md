# Sensor de iluminância BH1750

## Descrição

O BH1750 é um sensor digital de iluminância fabricado pela ROHM Semiconductor. Possui interface I²C, saída digital de 16 bits e resposta espectral próxima à sensibilidade fotópica do olho humano.

No protótipo desenvolvido para estimar a duração do brilho solar, foi utilizado o sensor BH1750 identificado como J11, operando no modo de alta resolução (H-Res).

## Especificações técnicas

| Parâmetro | Especificação |
|---|---|
| Fabricante | ROHM Semiconductor |
| Modelo | BH1750FVI |
| Grandeza medida | Iluminância (lux) |
| Interface | I²C |
| Tensão de alimentação | 2,4 a 3,6 V |
| Resolução digital | 16 bits |
| Resolução nominal H-Res | 1 lx |
| Resolução nominal H-Res2 | 0,5 lx |
| Tempo típico de medição H-Res | 120 ms |
| Corrente típica em operação | 0,12 mA |
| Corrente típica em power-down | 0,01 µA |
| Endereços I²C | 0x23 e 0x5C |
| Temperatura de operação | −40 °C a +85 °C |
| Resposta espectral | Predominantemente na região visível |

## Limite de medição na configuração utilizada

No modo H-Res, com o tempo de medição padrão, a iluminância é obtida pela relação:

L = N / 1,2

em que N representa a contagem digital do sensor.

Considerando a contagem máxima de 65.535, o limite nominal calculado é de aproximadamente 54.612,5 lux.

Valores próximos desse limite podem indicar saturação da leitura. O limite depende da configuração de tempo de medição do dispositivo.

## Aplicação no projeto

As leituras do sensor J11 foram utilizadas como variáveis de entrada dos modelos de aprendizagem de máquina. O BH1750 não mede diretamente a irradiância solar em W/m², e suas leituras não devem ser interpretadas como medidas de irradiância solar direta.
